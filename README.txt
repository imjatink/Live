HOW TO USE (simple steps)
1. Unzip this folder.
2. Open index.html in Chrome (double-click it). Do NOT use a preview window inside a chat app.
3. Flags are inside the file, so they always show.
4. Photos: the page first looks in the photos folder (see photos/PHOTO-NAMES.txt). Your own photo always wins.
   If there is no file, it asks Wikipedia for that city's main photo (needs internet). If that fails, it draws a skyline.
5. For GitHub: drag the whole folder in. Turn on GitHub Pages.
6. For OBS / YouTube: add a Browser Source, set it to 1920 x 1080, and point it to index.html.
All prices are SAMPLE numbers (USD), and hotel names are made up. Replace them with real data before you call them real.
